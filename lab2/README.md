# Виртуальный датчик для контроля процесса обжига

## Описание проекта

Лабораторная работа №2.

Цель проекта — разработка модели машинного обучения
для прогнозирования концентрации выходного продукта
на основе телеметрических измерений промышленной печи.

## Исходные данные

- data_train.csv — обучающая телеметрия;
- target_train.csv — обучающие лабораторные измерения;
- data_test_small.csv — тестовая телеметрия;
- target_test_small.csv — тестовые лабораторные измерения.

Телеметрия содержит 16 признаков.
Лабораторные измерения поступают нерегулярно.

## Используемые методы

1. Разведочный анализ данных (EDA).
2. Синхронизация временных рядов.
3. Создание лаговых признаков и скользящих статистик.
4. Обучение Ridge, Random Forest и Gradient Boosting.
5. Сравнение моделей по MAE, RMSE, MAPE и WAPE.
6. Анализ направления изменений и остатков.
7. Оценка важности признаков и вычислительной эффективности.

## Результаты

Лучшей моделью по MAE стала Gradient Boosting.

Метрики на независимой тестовой выборке:

| Метрика | Значение |
|---|---:|
| MAE | 0.0615 |
| RMSE | 0.0770 |
| MAPE | 33.76% |
| WAPE | 29.35% |
| Directional Accuracy | 56.19% |

Тестовая MAE улучшена примерно на 19.9%
относительно прогноза медианного значения концентрации.

## Запуск в Google Colab

1. Откройте Jupyter Notebook в Google Colab.
2. Загрузите четыре исходных CSV-файла в /content.
3. При необходимости установите зависимости:
```bash
   pip install -r requirements.txt
```
4. Выполните все ячейки ноутбука последовательно.

Для запуска используется стандартное CPU-окружение.

Важно: файлы, загруженные через панель Colab,
не сохраняются автоматически при перезапуске среды.

## Синхронизация данных

В работе принято предположение, что временная метка
лабораторного измерения обозначает время получения
результата, поэтому время отбора пробы оценивается
вычитанием 15 минут.

Если исходная временная метка означает время отбора,
этот сдвиг необходимо исключить.

## Интерпретация

Наиболее важными признаками оказались telemetry_12,
telemetry_15 и telemetry_11.

Существенную роль играют также временные лаги
и скользящие статистики.

Прогнозы могут использоваться для предварительного
мониторинга концентрации, но модель не предназначена
для автономного управления промышленной печью
без дополнительных испытаний.

## Ограничения

- Небольшое число размеченных наблюдений.
- Неизвестная физическая интерпретация датчиков.
- Недостаточная точность резких изменений концентрации.
- Неопределённость фактической задержки лабораторных замеров.
